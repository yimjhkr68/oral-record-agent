## 기능 개선

### 성능
- KnowledgeGraph: 노드 100개 이상 시 D3 `alphaDecay` / `velocityDecay` 튜닝
- KnowledgeGraph: 드래그 종료 후 `fx/fy = null` 설정으로 노드 자유 이동 복원
- graph_db: `_load()` 시 손상 레코드 수 로그 출력 (현재 무시만 함)

### UI/UX
- OntologyManager: 클래스/속성 인라인 편집 폼 (Draft 상태에서 직접 추가·삭제)
- TripleManager: 아카이브된 트리플 탭 분리 조회
- KnowledgeGraph: 노드 타입별 필터 토글 (범례 클릭 시 해당 타입 숨김/표시)
- 전체 UI: 다크/라이트 테마 전환

### API
- `GET /api/ontologies/{version_id}/diff?base={other_id}`: 버전 간 클래스·속성 diff
- `GET /api/triples/export?format=json|csv`: 트리플 내보내기
- API 에러 로깅 미들웨어 (요청/응답 상세 로그)

## 신규 기능 후보

- **Hive DB 실 연동 테스트** — hive_pipeline.py 와 새 GraphDB/TripleManager 연결
- **온톨로지 버전 간 diff 뷰** — 클래스·속성 추가/삭제/변경 시각화
- **트리플 일괄 가져오기** — CSV / JSON import (bulk_create 확장)
- **그래프 내보내기** — SVG/PNG export (d3 기반), GraphML/JSON-LD export
- **구술자료 복수 입력 배치 처리** — 여러 레코드 동시 추출 + 진행률 표시
- **ANTHROPIC_API_KEY 환경변수 설정 가이드** — .env 파일 템플릿 제공
- **온톨로지 자동 병합** — 두 Draft 버전의 클래스·속성을 AI가 통합 제안
