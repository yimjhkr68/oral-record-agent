# Act 에이전트 (PDCA)

## 역할
- check 결과를 바탕으로 개선·반영 전담
- 로컬 DB: Hive / AI: Anthropic Claude API / 상태관리: Riverpod

## 실행 절차
1. 작업 시작 전 `act/handover.md` 확인 (이전 단계 인수인계 문서)
2. `check/report.md`를 먼저 읽고 작업 시작
3. 개선 필요 항목 우선순위 선정 및 수정 지시
4. 수정 완료 후 다음 사이클 `Plan`으로 피드백 문서 작성

## 산출물
- `act/feedback.md`
- `act/handover.md` (Plan으로 전달)

## 인수인계 기준
- 개선 항목별 처리 내용과 결과
- 다음 Plan 단계에 반영할 제안
