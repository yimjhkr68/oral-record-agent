# 구술기록관리 앱 — 요구사항 명세 v3.0

- 작성일: 2026-03-24
- 플랫폼: Flutter Windows Desktop

---

## 1. 입력 유형

| 유형 | 지원 형식 | 자동 전사 | 파일 저장 |
|------|-----------|-----------|-----------|
| 영상 업로드 | mp4, avi, mov, mkv, wmv | ⚠️ 미지원(추후) | ✅ |
| 음성 업로드 | mp3, wav, m4a, aac, flac | ✅ Claude API | ✅ |
| 음성 녹음 | wav (실시간) | ✅ 녹음 후 전사 | ✅ |
| 문서 업로드 | txt, docx, pdf | N/A (텍스트 추출) | ✅ |
| 텍스트 직접 입력 | - | N/A | - |

## 2. 기록 생성 흐름

1. 홈 → 입력 방식 선택 (녹음 즉시 시작 / 파일 업로드 / 텍스트 입력)
2. 입력 완료 → 메타데이터 입력 화면
3. 메타데이터 저장 → 기록 상세 화면

## 4. 구술자/면담자 관리
- 기존 인물 검색 후 재사용
- 새 인물 인라인 추가 (다이얼로그)
- 인물별 전체 면담 기록 조회

## 5. AI 기능
- 음성/영상 자동 전사: Claude API (audio content block)
- 요약 생성: Claude claude-haiku-4-5
- PII 감지/마스킹: 정규식 기반

## 6. 기술 스택
- Flutter Windows + Riverpod + GoRouter + Hive
- record (마이크 녹음)
- file_picker (파일 선택)
- path_provider (파일 경로)
- archive (DOCX 파싱)
- http (Claude API)
